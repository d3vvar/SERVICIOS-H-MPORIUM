# Home Mporium · Catálogo inteligente de servicios

Web interna para consultar servicios de arquitectura, analizar necesidades escritas y preparar estimaciones preliminares.

## Abrir la aplicación

Abre `index.html` en un navegador moderno (Chrome, Edge o Firefox). No requiere instalar dependencias ni configurar servidor.

## Accesos de demostración

| Rol | Usuario | Contraseña | Alcance |
| --- | --- | --- | --- |
| Administrador | `admin` | `admin123` | Editar, crear y eliminar servicios; consultar y preparar estimaciones. |
| Colaborador | `equipo` | `equipo123` | Consultar el catálogo, analizar necesidades y preparar estimaciones. |

## Persistencia de datos

Los cambios del catálogo y las estimaciones se guardan en el navegador del equipo mediante almacenamiento local. Para una versión compartida entre compañeros, con cuentas reales y datos centralizados, el siguiente paso es conectar esta interfaz a una base de datos y sistema de autenticación.

Los precios se muestran en soles peruanos (PEN). Los resultados son preliminares y requieren revisión profesional antes de emitir una cotización.
